cloudsound_999 — a local SoundCloud audio downloader for macOS
==============================================================

It's a native Mac app (its own window, no web browser needed). It queues SoundCloud
tracks and playlists, downloads the audio with yt-dlp into a folder you choose, and shows
progress, pause/resume and remove like a torrent client. Works on Apple Silicon and
Intel Macs running macOS 12 or later. Everything runs on your own Mac; nothing is
uploaded anywhere.

Please only download audio you have the rights to: tracks the artist made
downloadable, Creative Commons work, or your own uploads.


1. One-time setup (Terminal)
----------------------------
You need Homebrew (https://brew.sh). Then run:

    brew install python yt-dlp ffmpeg

2. Install the app
------------------
From the .dmg: drag cloudsound_999 onto the Applications shortcut next to it.
From the .zip: drag cloudsound_999.app into your Applications folder.
Then drag it onto your Dock if you like.

3. First open
-------------
This app isn't from the App Store or a registered Apple developer, so macOS blocks it
the first time. To allow it:

  • Double-click it once and dismiss the warning, then
  • open System Settings → Privacy & Security, scroll down, and click "Open Anyway".
    (On older macOS you can instead right-click the app → Open → Open.)

The first launch takes about a minute while it sets itself up. In the background it also
adds a music-analysis library (about 60 MB) inside the app's own folder, used for BPM/key.

Using it
--------
  • Paste SoundCloud links into the Add bar (⌘L jumps there), or drag a link onto
    the app's Dock icon or window to queue it.
  • The player under the Add bar plays your finished tracks with album art and a live
    oscilloscope. ⟳ Auto turns auto-play to the next track on or off. Space = play/pause.
  • ⌘Q quits. Unfinished downloads are paused and can be resumed next time.
  • The Dock icon shows how many downloads are running.
  • Downloads go to ~/Music/cloudsound_999 by default. Change it with File → Choose
    Download Folder (⌘O) or in Settings (⌘,).
  • Organize tab: title, artist, BPM and key (Camelot) of your finished tracks. Click a
    header to sort. "?" = the detectors weren't sure; hover a BPM for ½ / ×2. Settings has a
    BPM range for your genre. BPM/key tags written by Mixed In Key, rekordbox, etc. are
    used first. The search box (⌘F) finds tracks by name, key ("8A", "Fm") or BPM
    ("128", "120-130").
  • Skins (Matrix, LymeWire, Napsterr, HotFries, JoeKool, POSTAL, Noir) are in
    View → Skin (⌘1–⌘7) or in the User menu.

Keep yt-dlp current if downloads start failing:

    brew upgrade yt-dlp

The app's own data (settings, queue, log) lives in
~/Library/Application Support/cloudsound_999. Delete that folder to reset it.
