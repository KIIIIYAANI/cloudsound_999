cloudsound_999 for Windows
==========================

INSTALL
1. Right-click the downloaded zip > Extract All. Keep the extracted folder somewhere
   permanent, such as Documents or C:\Programs. Don't run it from inside the zip.
2. Open the folder and double-click cloudsound_999.exe.
3. Windows may show "Windows protected your PC" because the app isn't code-signed.
   Click "More info", then "Run anyway". You only need to do this once.
4. The app opens in its own window. Close the window to quit. Downloads that weren't
   finished come back as Paused next time.

Tip: right-click cloudsound_999.exe > Show more options > Send to > Desktop (create
shortcut), or pin it to Start.

INCLUDED
yt-dlp (downloading) and FFmpeg (conversion, tags, cover art) are in the "tools" folder.
You don't need to install anything else. yt-dlp updates itself about once a week so
SoundCloud keeps working.

USING IT
- Paste SoundCloud track, playlist or profile links and click Add to queue. You can
  also drop links onto the window.
- Completed tracks play in the built-in player. The Organize tab lists title, artist,
  BPM and key (Camelot), sortable by any column. Search with Ctrl+F.
- Skins: User menu, or Ctrl+1 to Ctrl+7.
- Your music goes to Music\cloudsound_999. Change it with Folder... or in Settings.
- BPM/key: values already written by DJ software (Mixed In Key, rekordbox, Serato...)
  are used first. Otherwise the app's built-in analyser estimates them. The Mac version
  uses Essentia, which has no Windows build.

FILES
App data and log: %LOCALAPPDATA%\cloudsound_999
To uninstall, delete the app folder and that data folder.

Only download audio you have the rights to. cloudsound_999 is not affiliated with SoundCloud.
